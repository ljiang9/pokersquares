# 🃏 Poker Squares 接龙

一个极简的扑克接龙小游戏：标准 52 张牌洗牌后，每次只发 1 张，
你把它放到 5×5 网格的任意空格里。25 张放完，每行每列各组成一手
5 张牌，按**美式计分（American point system）**打分，10 手总和就是你的总分。

没有网络、没有依赖，纯标准库。

## 玩法

1. 运行后进入交互模式，每次发一张牌；
2. 输入 `行 列`（1–5），比如 `2 3`，把牌放到第 2 行第 3 列；
3. 放满 25 张后自动计分，打印每行每列的牌型和总分。

放牌前想好：牌一旦放下就不能移动/撤销——这就是全部的策略深度。

## 计分表（美式）

| 牌型 | 分数 |
|---|---|
| 皇家同花顺（T,J,Q,K,A 同花） | 100 |
| 同花顺 | 75 |
| 四条 | 50 |
| 葫芦 | 25 |
| 同花 | 20 |
| 顺子（含 A,2,3,4,5 轮子顺） | 15 |
| 三条 | 10 |
| 两对 | 5 |
| 一对 | 2 |
| 高牌 | 0 |

理论最高 500 分（10 手全是皇家同花顺——祝好运）。

## 运行

需要 Python 3.10+，无第三方依赖。

```bash
# 交互玩一局
python -m pokersquares

# 固定牌序（可复现，适合和朋友比同一副牌）
python -m pokersquares --seed 42

# 看贪心机器人自动玩一局
python -m pokersquares --auto --seed 7
```

命令行选项：

```
--seed N   用固定随机种子洗牌（默认用 secrets 真随机）
--auto     贪心机器人自动玩一局：每张牌放到（行潜力+列潜力）最大的空格
```

## 示例

```
$ python -m pokersquares --auto --seed 7
🤖 贪心机器人自动开局…

第 1张  6♥ → (1,1)
第 2张  8♠ → (1,3)
...
── 计分明细 ──
  行1：一对（2 分）
  ...
总分：59 分
```

## 验证

```bash
python -m py_compile pokersquares.py __main__.py
python - <<'EOF'
import sys; sys.path.insert(0, '.')
from pokersquares import hand_score, Grid

# 1) 计分表 11 种牌型逐一核对
cases = [
    ([(10,1),(11,1),(12,1),(13,1),(14,1)], 100),  # 皇家同花顺
    ([(9,1),(8,1),(7,1),(6,1),(5,1)], 75),        # 同花顺
    ([(14,0),(14,1),(14,2),(14,3),(13,0)], 50),   # 四条
    ([(9,0),(9,2),(9,3),(8,0),(8,2)], 25),        # 葫芦
    ([(14,1),(13,1),(9,1),(5,1),(3,1)], 20),      # 同花
    ([(9,0),(8,1),(7,2),(6,3),(5,0)], 15),        # 顺子
    ([(14,0),(5,1),(4,2),(3,3),(2,0)], 15),       # 轮子顺 A2345
    ([(7,0),(7,2),(7,3),(5,0),(4,1)], 10),        # 三条
    ([(6,0),(6,2),(5,2),(5,3),(3,2)], 5),         # 两对
    ([(6,0),(6,2),(13,1),(12,1),(9,2)], 2),       # 一对
    ([(14,0),(13,1),(12,2),(11,3),(9,0)], 0),     # 高牌
]
for cards, exp in cases:
    assert hand_score(cards) == exp, (cards, hand_score(cards), exp)

# 2) 已知网格：手工算出总分 194，程序必须算出 194
g = Grid()
rows = [
    [(10,1),(11,1),(12,1),(13,1),(14,1)],  # 皇家同花顺 100
    [(2,0),(2,1),(2,2),(2,3),(3,0)],       # 四条 50
    [(9,0),(9,2),(9,3),(8,0),(8,2)],       # 葫芦 25
    [(7,0),(7,2),(7,3),(5,0),(4,1)],       # 三条 10
    [(6,0),(6,2),(5,2),(5,3),(3,2)],       # 两对 5
]
for r, row in enumerate(rows):
    for c, card in enumerate(row):
        g.place(r, c, card)
assert g.full()
assert [hand_score(g.cells[r]) for r in range(5)] == [100, 50, 25, 10, 5]
assert [hand_score([g.cells[r][c] for r in range(5)]) for c in range(5)] == [0, 0, 0, 2, 2]
assert g.score() == 194
print("全部断言通过")
EOF
```

（2026-10-05 实测：11 种牌型全对；已知网格行 `[100,50,25,10,5]`、列 `[0,0,0,2,2]`、总分 194 与手工计算一致；
`--auto --seed 7` 完成 25 次放置；同 seed 两次运行输出完全一致；管道输入 25 个坐标可走完交互流程。）

## 已知限制

- 贪心机器人只是局部启发式（对子/三条/同花/顺子潜力加权），不是最优策略，
  典型得分在几十分到一百多分；想挑战可以自己写更强的 bot 替换 `choose_cell`。
- 放下的牌不能移动或撤销——这是规则，不是 bug。
- `--seed` 只控制洗牌，`--auto` 的贪心决策本身是确定性的。
- 终端需要支持 Unicode（♠♥♦♣）和 ANSI 颜色；不支持时牌面符号可能显示为方框，
  可把 `card_str` 的 `color` 关掉或自行替换符号。
- 计分采用美式计分表的经典版本；轮子顺 A,2,3,4,5 按顺子 15 分计。
